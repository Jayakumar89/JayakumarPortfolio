# Jayakumar Raju — Personal Portfolio

A responsive, single-page portfolio for a Lead Automation and Quality Assurance Engineer. Built with plain HTML, CSS and JavaScript.

## Open in IntelliJ IDEA

1. Download and extract `JayakumarPortfolio_Full.zip`.
2. Open IntelliJ IDEA.
3. Choose **File → Open** and select the extracted `JayakumarPortfolio_Full` folder.
4. Open `index.html`.
5. Right-click the editor and choose **Open in Browser → Chrome** (menu wording may vary by IntelliJ version).

No Maven, Gradle, Node.js or build command is required.
